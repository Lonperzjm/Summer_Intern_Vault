## 推荐汇报结构（8–10 分钟）

### 第 1 页：问题与最初想法（约 45 秒）

Flow Matching 学到的边缘速度为

$$
v(x,t)=\mathbb E[u_t\mid X_t=x].
$$

当多个 conditional transport 分支局部接近时，这个平均速度在分布层面仍正确，但对有限 NFE 下的单条样本未必是好的 sample-wise transport direction。

原始算法直觉：

$$
\text{trial}\to\text{detect}\to\text{reject/rollback}
\to\text{skip}\to\text{validate/correct}.
$$

需要强调：不是始终增大步长，而是在 trial endpoint 显示不可信之后回滚，搜索异常区另一侧的可信出口；失败则 fallback 到 shrink。

口头表述：

> 我最初关注的是局部多模态导致的 velocity averaging。传统 adaptive solver 会缩步、更精确地跟随 marginal ODE；我想问的是，能不能在检测到局部坏场后主动跨过去，选择另一种仍然合理的 transport coupling。

### 第 3 页：文献地图与当前方向的位置（约 60 秒）

```text
生成 ODE / Flow Matching solver
├── 经典积分器：Euler / RK2 / RK4 / RK45 / AB
├── 模型专用参数优化：Bespoke / BNS / Differentiable Search
├── 辅助网络：FlowTurbo / BA-Solver
├── Training-free 高阶公式：Flow-Solver / RF-Solver / STORK / CAB
├── 时间网格与预算：BOSS / FastFlow / SharpEuler / Entropy schedule
├── 轨迹选择：FDS / Reject-and-Skip（候选）
└── 系统与并行：SADA / ParaFlow
```

当前方向不是传统意义上单纯提高阶数，而更接近“轨迹选择 / coupling intervention”。这也是为什么仅用 RK4 reference error 不能判断方法最终是否成功。

| 方法 | 主要目标 | 与当前想法的区别 |
|---|---|---|
| Bespoke / BNS | 离线优化 solver 系数和时间变换 | 优化 marginal ODE 积分 |
| RF-Solver | training-free 高阶 Taylor 公式 | 提高时间积分阶数 |
| FastFlow | UCB bandit 选择跳步，减少 NFE | 假设速度场可信，目标是加速 |
| BA-Solver | SideNet + 双 anchor 插值 | 学习区间 velocity interpolation |
| STORK / CAB | 端点稳定化或历史速度修正 | 结构化高阶积分，是 endpoint 方向的重要 baseline |
| BOSS / SharpEuler | 非均匀时间网格与预算分配 | 如果只需末端加密，这是更简单的 baseline |
| FDS | 用 divergence 选择较可信的邻近状态 | 最接近当前“轨迹选择”问题，但在空间中修正状态 |
| Adaptive Heun / step-doubling | 截断误差控制 | shrink baseline，不识别 conditional ambiguity |
| Reject-and-Skip | 局部状态不可信时改变 coupling | 尚需非 oracle detector 和真实分布收益 |

严谨说法：FastFlow 与“自适应跳步”表面相似，但研究目标不同；它仍是必须比较的强相关 baseline，不能说完全无关。

### 第 4 页：解析 2D toy——机制存在，但目标不是 ODE accuracy（约 90 秒）

![[research/assets/experiments/reject-and-skip-crossing-toy/trajectories.png]]

设置：两个带高斯管宽的近交叉线性传输分支；可以解析获得 marginal velocity、conditional velocity variance、真实密度和人工 branch label。

关键结果：

- skip + corrector 约 15–17 NFE，与 16-NFE Heun 同量级；
- 相比 8-NFE Euler，多个 $\delta/\sigma$ 条件下 endpoint outlier rate 更低；
- skip 对 RK4 reference 的 RMSE 很大，但 branch retention 约 98%–99%；
- 单次 SWD 多数位于 256 样本 target-vs-target sampling floor 内，但不能据此宣称严格优于 adaptive Heun；
- 普通 adaptive Heun 有时也会偶然跨区，是最重要的 novelty 风险。

核心解释：

> Toy 支持的是“结构化离散偏置可以选择另一种合理 coupling”，不是“skip 是更准确的 ODE solver”。因此必须把 ODE accuracy、endpoint distribution 和 coupling behavior 分开评价。

诚实边界：toy 使用 oracle conditional velocity variance；这不是神经模型中可部署的 detector。

### 第 6 页：真实模型上的机制检查——内部 return 暂未找到（约 60 秒）

按原始机制扫描

$$
x_{\mathrm{trial}}^{(m)}=x_0+mh v_0,
\qquad m\in\{1,2,3,4,6,8\},
$$

并比较 relative velocity change、angle 与 projected endpoint consistency。

结果：

- 两个 seed 上都没有稳定、可复现的内部 velocity return；
- 表面 return 主要集中在噪声端边界，且 projected endpoint consistency 较差；
- 当前 Euler-ray 候选构造不支持直接实现完整 skip。

与此同时，高维路径诊断显示：RK4-1000 的多尺度 turning ratio 在 $k=2$ 到 64 的中位数约 0.90 降至 0.83，没有 $R_k<0.5$ 的窗口。路径更接近持续转弯的高维弧线，而不是隐藏在 PCA 平面外的高频折线。

这里要明确说：

> 这否定的是当前出口构造，不是否定所有 reject-and-skip；但目前没有理由继续盲目扩大该版本实验。

### 第 7 页：最稳定的新现象——Endpoint Boundary Layer（约 90 秒）

![[research/assets/experiments/official-1rf-solver-diagnostics/terminal-vs-interior.png]]

8 月 3 日局部误差诊断：最后区间 $t\in[0.95005,1]$ 的 Heun local error 中位数约为此前区间合并中位数的 135.94 倍，并贡献全部独立局部误差平方和的 99.22%。

训练时间采样属于 $[0.001,1)$，不会精确看到 $t=1$；Heun/RK4 末步会查询 $t=1$，midpoint 不会。把末端标签从 1 截到 0.999 只改善约 31%，说明不只是单点外推，还可能存在更宽的边界层。

进一步定义沿轨迹的离散加速度与 jerk：

$$
a_{i+\frac12}=\frac{v_{i+1}-v_i}{h},
\qquad
j_{i+1}=\frac{a_{i+\frac32}-a_{i+\frac12}}{h}.
$$

![[research/assets/experiments/official-1rf-path-development/euler-100-rapid-change-curves.png]]

512 条随机 Euler-100 路径：

- 512/512 的最大 jerk 都位于 $t=0.98002$；
- 平均 acceleration RMS 在 $t=0.985015$ 最大，为 15.85；
- 平均 jerk RMS 在 $t=0.98002$ 最大，为 1013.73；
- 中段约 $t\approx0.55$ 最平缓；起点也有次强边界层，但远弱于终点。

谨慎解释：有限差分 jerk 含 $1/h^2$ 放大，当前状态来自 Euler 路径。因此现在只能说“强 endpoint boundary-layer 证据”，不能说已经证明连续速度场在 $t=1$ 发散。

### 第 8 页：当前判断与下一步（约 45 秒）

当前判断：

1. Toy 证明 coupling intervention 的机制可能存在；
2. 当前真实模型内部 velocity-return 构造失败；
3. 最强、最可复现的真实现象是 endpoint boundary layer；
4. 在继续设计 solver 前，应先验证该现象是否为真实连续场性质。

下一步最小闭环：

1. 用高精度 RK4 状态在相同时间网格重新计算 acceleration/jerk；
2. 用自动微分 JVP 直接计算
   $$
   \frac{d}{dt}v_\theta(x(t),t)
   =\partial_t v_\theta+J_xv_\theta\,v_\theta;
   $$
3. 在 $t=0.9,0.95,0.97,0.98,0.99,0.995,0.999$ 拟合随 $1-t$ 的增长规律；
4. 若成立，再比较 endpoint timestep refinement、时间重参数化、中段低阶+末端高阶、提前终止；
5. 最终在严格等 NFE 下使用 FID/KID、precision/recall、feature OOD 判断生成质量。

## 可能被问的问题与回答

### Q1：所以你的 skip 在真实模型上有效吗？

**答：目前不能说有效。** Toy 上 oracle 机制有信号，但真实 1-RF 的当前 Euler-ray velocity-return 没找到可靠内部出口，也没有做等 NFE 的 FID/KID。因此真实模型方法尚未成立。

### Q2：为什么 skip 的 RK4 error 很大还能说可能更好？

因为 skip 可能有意改变 sample-wise coupling。RK4 error 只衡量是否跟随原 marginal ODE；最终目标分布是否更好必须用 FID/KID、precision/recall、OOD 判断。Toy 中存在“RK4 RMSE 大但 endpoint outlier 较低、branch retention 高”的情况。

### Q3：这和 adaptive solver / FastFlow 有什么区别？

Adaptive solver 检测截断误差并 shrink；FastFlow 学 dataset-level 跳步策略以省 NFE。Reject-and-skip 的预期差异是 instance-aware 地检测局部状态不可信、rollback、验证出口并允许改变 coupling。但这只是目标定义，尚未通过真实模型结果证明优势。

### Q4：endpoint 问题是不是因为模型没训练 $t=1$？

这是重要因素，但可能不是全部。训练确实只采 $t<1$；Heun 精确查询 $t=1$，midpoint 不查询。可是在消融中把标签截到 0.999 只改善约 31%，且 Euler-100 在 $t\approx0.98$ 已开始急剧增长，说明可能存在一个有限宽度边界层，而不只是单点 OOD。

### Q5：jerk 1000 多是不是纯数值假象？

现在不能排除。Jerk 是二阶有限差分，含 $1/h^2$ 放大；因此不应拿绝对值直接宣称奇异。可信证据是位置在 512 个样本上高度一致地集中于末端。下一步用 RK4 状态和 JVP 验证。

### Q6：为什么不直接在 ImageNet/SiT 上做？

CIFAR-10 1-RF 采样快、可做大量轨迹诊断和 ablation，适合作为机制验证。只有 detector/solver 闭环成立后，再迁移到更大的 SiT/ImageNet backbone 做正式生成质量对照，避免昂贵但没有机制结论的实验。

### Q7：自训模型为什么不用了？

100k checkpoint 可生成，但约 110k 后优化失稳，200k raw/EMA 都崩坏；100k 的 50k clean-FID 为 17.96，不够成熟。为了避免 backbone 质量混淆 solver 结论，改用官方 1-RF。

### Q8：这周最重要的负结果是什么？

当前 Euler-ray velocity-return 在真实模型内部没有稳定出口。这个结果阻止了我直接堆一个看似新颖但机制不成立的 skip solver。

### Q9：这周最重要的正结果是什么？

完成了从解析 toy 到成熟真实 backbone 的诊断链，并将真实模型最强困难稳定定位到图像端 endpoint boundary layer；同时明确了 ODE accuracy、distribution quality 和 coupling behavior 必须分开评估。

### Q10：你到底看了多少论文，哪些是精读？

**答：**系统通读了 solver 表中的传统数值法、约 20 条 FM 专用 solver 和约 18 条轨迹/少步方法；其中 Bespoke、BNS、RF-Solver、FastFlow、BA-Solver 形成了独立精读笔记/wiki，FDS 有原始论文笔记和研究延伸。STORK、CAB、BOSS、SharpEuler、FlowTurbo、SADA、ParaFlow 等已经进入 taxonomy 和选型比较，但不把它们全部表述成同等深度的精读。

## 不要在组会上这样说

- 不要说“已经提出了一个优于现有方法的新 solver”；真实模型尚无生成质量收益。
- 不要把早期的 $l\ll\Delta\ll E(d_{\min})$ 当成已证理论；这些尺度关系尚未操作性定义。
- 不要说“高维交叉一定很少，所以问题只在双交叉”；高维概率分析只是早期直觉。
- 不要说“jerk 发散已证明 endpoint singularity”；目前只是有限差分证据。
- 不要用 reference RMSE 代替生成质量，也不要把单坐标反转解释为 OOD。
- 不要说 FastFlow 完全不相关；应称为目标不同但必须比较的强 baseline。

## 备查数字

- Toy：256 samples/condition，$\delta/\sigma\in\{0,0.25,0.5,1,2,4\}$，8 base steps，512-step RK4 reference。
- Official 1-RF：61,804,419 parameters，checkpoint step 800001，CIFAR-10 32×32 pixel space。
- Detector：step-doubling Spearman 0.9977；内部 Top-10% overlap 97.4%；Euler–Heun defect overlap 75.7%。
- Endpoint：最后区间 local-error median 约为此前 135.94 倍；独立局部误差平方集中度 99.22%。
- RK4-1000 turning：$R_k$ median 从 $k=2$ 的 0.9002 到 $k=64$ 的 0.8283，无 $R_k<0.5$。
