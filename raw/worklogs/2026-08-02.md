## 实验观察

- 实验 ID：analytic crossing-flow toy v3
- 改动变量：同步最小中心距离与管宽比 $\delta/\sigma$；solver 类型；是否 shrink / skip / corrector
- 观察结果：
  - reject-and-skip 在约 15–17 NFE 下，相比 8-NFE Euler 观察到更低的终点 outlier rate；其单次 SWD 大体处在 256 样本的 target-vs-target sampling floor 内
  - skip 与 512-step RK4 的 reference RMSE 很大，但 branch retention 约 98%–99%；oracle shrink 更接近 marginal ODE，却会采用不同的样本级 coupling
  - 因此 skip 当前更像“绕过局部 marginal velocity averaging、主动改变 coupling”的结构化离散偏置，而不是更准确的 ODE solver
  - 普通 adaptive Heun 在一些样本上也会用大步偶然跨过异常区，得到类似终点行为；这构成必须正面对比的 novelty 风险
  - 当 $\delta/\sigma$ 增大，oracle shrink 的平均 NFE 从约 221 降到 37，skip 触发率从接近 100% 降到约 13%，符合分支更易区分时 ambiguity 区域缩小的预期
- 日志/配置/图表：`/home/lonper/homework/Summer_Intern/runs/toy_crossing_v3/`
- 当前只能够说明：oracle detector 下 reject-and-skip 的机制具有可验证信号；不能说明它已经优于 adaptive Heun，也不能说明该机制能直接迁移到神经网络速度场

## 遇到的问题

- 问题：第一版 $\delta$ 构造有几何定义错误——它只改变 $t=0.5$ 时的距离，两个分支仍会在稍后相同 $t$、相同 $x_t$ 处真正相交，不能称为 avoided crossing
- 已尝试：显式检查同步条件 $m_1(t)=m_2(t)$；将相对位移改为
  $$m_1(t)-m_2(t)=(-\delta,-2+4t),$$
  使得
  $$\min_t\|m_1(t)-m_2(t)\|=\delta$$
  且只有 $\delta=0$ 时真正相交
- 结果：完成 v3 全量重跑；旧 `runs/toy_crossing_v2` 保留用于 provenance，但已加 `OBSOLETE.md`，不得再作为 avoided-crossing 结果引用
- 是否影响计划：是——旧 v2 的数值结论作废，以 v3 为准；同时说明 toy 几何必须先做解析 sanity check

- 问题：当前 detector 使用真实 conditional velocity variance，是解析 oracle，神经 backbone 中不可直接获得
- 已尝试：先将 oracle 用作策略可行性检验，并保留 velocity change、Euler–Heun defect、divergence、forward/backward consistency 等候选 detector
- 结果：策略层有初步信号，检测层尚未解决
- 是否影响计划：是——迁移 CIFAR 前必须先做非 oracle detector 和 false-skip 对照

- 问题：`skip + corrector` 当前先验证未修正的候选出口，再做梯形修正，没有对修正后的最终状态重新验证
- 已尝试：已识别该实现缺口，尚未完成出口二次验证
- 结果：当前 corrector 结果只作为初步对照
- 是否影响计划：是——下一版 solver 必须加入 corrected endpoint validation 与失败回退

## 临时想法

- 假设：Reject-and-Skip 的合理定位不是“提高 marginal ODE 数值精度”，而是检测到模型局部不可信后，有控制地选择另一种传输 coupling
- 触发来源：skip 的 endpoint distribution 尚可，但 reference RMSE 很大且 branch retention 接近 1
- 最小验证方式：设计真正的正例/反例 toy，并在相同 NFE 下同时报告分布指标、reference error、false skip 和 coupling diagnostic

- 假设：传统 adaptive Heun 的 endpoint-only embedded error 可能看不到步长内部异常区，因此会偶然产生 blind skip；显式方法的价值必须来自事前检测、rollback、出口验证与失败回退，而不是“步长变大”本身
- 触发来源：单样本轨迹中 adaptive Heun 未 rejection 就跨过异常区，并与 skip 几乎重合
- 最小验证方式：增加区间内部 probe、速度夹角和 forward/backward consistency，对比 adaptive Heun 的成功跨越与错误跨越
